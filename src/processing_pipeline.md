# Processing Pipeline

The Autosync application will process climate data through a sequence of stages.

## Stage 1 - Input

Temperature and relative humidity datasets are provided to the application.

## Stage 2 - Loading

The data loader module loads the required datasets.

## Stage 3 - Processing

The loaded data is prepared for analysis.

## Stage 4 - Analysis

The analysis module calculates useful climate measurements.

## Stage 5 - Comparison

Temperature and humidity information can be compared between sensors and locations.

## Stage 6 - Output

The processed results are passed to the application or visualization layer.

## Pipeline

Input → Loading → Processing → Analysis → Comparison → Output
