# Analysis Service

The analysis service is responsible for processing prepared climate data and producing analytical results.

## Responsibilities

The analysis service may:

- Calculate climate measurements.
- Compare temperature values.
- Compare relative humidity values.
- Identify differences between observations.
- Prepare results for the output layer.

## Input

The service receives validated and prepared climate data.

## Output

The service produces structured analysis results for further use by the application and visualization layers.
