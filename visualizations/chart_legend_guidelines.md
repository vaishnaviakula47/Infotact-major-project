# Chart Legend Guidelines

Charts in the Autosync project should use clear legends to explain different data series.

## Legend Information

Legends may identify:

- Locations
- Sensors
- Temperature
- Relative humidity
- Comparison categories

## Design Guidelines

Legends should:

- Use clear labels.
- Be easy to read.
- Remain consistent across related charts.
- Avoid unnecessary information.

## Purpose

Clear legends help users understand which data series are represented in each visualization.
