# Responsive Dashboard Design

The Autosync dashboard should be designed so that climate information remains understandable on different screen sizes.

## Dashboard Elements

The dashboard may contain:

- Metric cards
- Climate comparison charts
- Opportunity tables
- Filters
- Climate indicators

## Layout

Dashboard elements should be organized clearly so that important information remains visible when the screen size changes.

## Readability

Charts, labels, tables, and indicators should remain easy to read.

## Purpose

A responsive layout improves the usability of the Autosync visualization interface.
