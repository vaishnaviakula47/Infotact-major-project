# Microclimate Visualization

Microclimate visualization will combine temperature and relative humidity information.

## Temperature Component

Temperature values can be displayed to show differences between sensors and locations.

## Humidity Component

Relative humidity values can be displayed alongside temperature information.

## Sensor Comparison

Charts can compare measurements from multiple sensors.

## Location Comparison

Visualizations can compare climate conditions between different locations.

## Purpose

The visualization should make differences in microclimate conditions easy to identify.
