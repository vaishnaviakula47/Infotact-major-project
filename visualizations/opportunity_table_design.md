# Opportunity Table Design

The Autosync dashboard can use a table to present identified microclimate opportunities.

## Table Information

The table may contain:

- Location
- Date
- Time period
- Sensor
- Temperature difference
- Humidity difference
- Opportunity score
- Opportunity indicator

## Purpose

The table provides a structured way to inspect individual analysis results.

## Usability

Important values should be clearly displayed so that users can compare multiple results easily.

## Integration

The opportunity table can receive processed results from the analysis and application layers.
