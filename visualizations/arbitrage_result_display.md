# Arbitrage Result Display

The visualization layer will present the results of the microclimate arbitrage analysis.

## Information to Display

The results may include:

- Location
- Time period
- Temperature difference
- Humidity difference
- Sensor information
- Potential opportunity indicator

## Visual Representation

Results can be presented using charts, tables or highlighted indicators.

## Comparison

Locations with notable climate differences can be displayed for easier comparison.

## Purpose

The result display should help users understand the output of the arbitrage analysis.
