# Metric Cards

The Autosync dashboard can use metric cards to display important climate analysis values.

## Possible Metrics

Metric cards may display:

- Average temperature
- Average relative humidity
- Temperature difference
- Humidity difference
- Number of identified opportunities

## Design

Each metric card should display one important value with a clear label.

## Purpose

Metric cards provide a quick overview of important analysis results before users examine detailed charts and tables.
