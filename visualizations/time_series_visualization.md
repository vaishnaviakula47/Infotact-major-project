# Time Series Visualization Design

## Purpose

Time series visualizations show how climate conditions change over time.

## Main Variables

The dashboard can visualize:

- Temperature.
- Relative humidity.
- Date and time.
- Location.
- Sensor.

## Recommended Chart

A line chart is suitable for displaying temperature or humidity observations over time.

The horizontal axis should represent date and time.

The vertical axis should represent the selected climate measurement.

## Temperature Time Series

Temperature observations can be displayed as a continuous line to show:

- Increasing temperature.
- Decreasing temperature.
- Stable periods.
- Sudden changes.
- Repeated patterns.

## Humidity Time Series

Humidity observations can be displayed using the same time-based structure.

This allows users to observe humidity changes across different periods.

## Sensor Comparison

Users should be able to select or compare sensors when multiple sensors are available.

This helps identify differences in local climate conditions.

## Visualization Requirements

The chart should provide:

- Clear axis labels.
- Readable time information.
- A meaningful title.
- Sensor or location identification.
- Tooltips for individual observations.

## Project Relevance

Time series charts help users understand how micro-climate conditions change over time and support the identification of periods with significant climate differences.
