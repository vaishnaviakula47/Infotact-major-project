# Sensor Comparison Chart Design

## Purpose

The sensor comparison chart displays climate differences between sensors at the same location or during a selected time period.

## Data

The visualization may use:

- Sensor identifier.
- Temperature.
- Relative humidity.
- Date and time.
- Location.

## Chart Purpose

The chart should make it easy to compare climate measurements across sensors.

## Suitable Chart Types

Possible chart types include:

- Bar chart for comparing summary values.
- Line chart for comparing sensor behavior over time.

The selected chart should depend on whether the goal is comparison of summary values or changes over time.

## Sensor Identification

Each sensor should be clearly identifiable.

The chart should avoid ambiguous labels when several sensors are displayed.

## User Interaction

Where supported, users should be able to select:

- Location.
- Sensor.
- Climate variable.
- Time period.

## Interpretation

Differences between sensors may represent genuine local micro-climate variation.

The visualization should present the differences clearly without automatically labeling them as errors.

## Project Relevance

Sensor comparison supports micro-climate analysis by showing localized differences that may later be considered during opportunity analysis.
