# Dashboard Components

The Autosync dashboard will present climate analysis results in an easy-to-understand format.

## Main Components

The dashboard may contain:

- Temperature comparison chart
- Relative humidity comparison chart
- Location comparison
- Time-based climate chart
- Opportunity summary
- Climate difference information

## Climate Information

The dashboard can display:

- Location
- Sensor
- Date and time
- Temperature
- Relative humidity

## Purpose

The dashboard components should help users understand climate differences and analysis results clearly.
