# Color Usage Guidelines

The Autosync visualizations should use colors consistently to communicate different types of information.

## Usage

Colors may be used to distinguish:

- Different locations
- Different sensors
- Temperature measurements
- Relative humidity measurements
- Opportunity indicators

## Guidelines

Colors should:

- Remain consistent across related charts.
- Have clear meanings.
- Keep text and data readable.
- Avoid unnecessary visual complexity.

## Purpose

Consistent color usage helps users interpret climate visualizations more easily.
