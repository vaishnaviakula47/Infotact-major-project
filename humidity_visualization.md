# Humidity Visualization

## Overview

This visualization focuses on Relative Humidity (RH) data collected from different sensors.

RH means Relative Humidity. It represents the amount of moisture present in the air.

## Data Sources

The visualization will use RH datasets such as:

- baltimore_rh.csv
- Other available RH sensor datasets

## Visualization Plan

The humidity data will be represented using a time-series graph.

- X-axis: Time
- Y-axis: Relative Humidity (RH)
- Sensor comparison: Humidity readings from different sensors will be compared.

## Purpose

The purpose of this visualization is to identify humidity variation between sensors and across different time periods.

It will help us observe:

- Changes in humidity over time.
- Differences between sensor readings.
- High and low humidity periods.
- Similarities and variations between sensors.

## Expected Outcome

The visualization will help us understand humidity patterns over time and compare readings from different sensors.
