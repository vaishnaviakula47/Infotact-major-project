# Data Cleaning Documentation

## 1. Missing Values
Check all temperature and relative humidity datasets for missing values.
Missing values should be identified before performing analysis.

## 2. Duplicate Records
Check the datasets for duplicate rows and records.
Duplicate records should be removed or handled before analysis.

## 3. Date and Time Format
Check the `Date - Time` column to ensure that dates and times are in a consistent format.

## 4. Invalid Temperature Values
Check temperature sensor columns for invalid or unrealistic values.
Invalid values should be identified before statistical analysis.

## 5. Invalid Humidity Values
Check relative humidity (RH) columns for invalid values.
Humidity values should be checked to ensure they are within a valid range.

## 6. Standardizing Column Names
Use consistent and clear column names across datasets to make analysis easier.

## 7. Preserve Raw Data
The original raw datasets should not be modified.
Any cleaned or processed data should be saved separately from the original files.
