# Climate Dataset Relationship

The Autosync project contains temperature and relative humidity datasets for different locations.

## Temperature Data

Temperature datasets contain observations recorded by multiple sensors over time.

## Relative Humidity Data

Relative humidity datasets contain humidity observations from corresponding locations.

## Relationship

Temperature and relative humidity data can be examined together to understand microclimate conditions.

## Common Information

The datasets can be related using information such as:

- Location
- Date
- Time
- Sensor observations

## Purpose

Combining temperature and humidity information can provide a more complete view of microclimate conditions.
