# City Dataset Mapping

The Autosync project contains climate datasets associated with different locations.

## Dataset Types

Each location may contain:

- Temperature dataset
- Relative humidity dataset

## Mapping

Temperature and humidity files can be identified using their location names and measurement type.

## Purpose

City-based dataset mapping helps the project identify the appropriate climate files for analysis.

## Analysis Usage

The mapped datasets can later be used for location-based temperature and humidity comparisons.
