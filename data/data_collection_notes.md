# Data Collection Notes

The Autosync project uses climate observations collected from multiple locations and sensors.

## Collected Measurements

The datasets contain:

- Temperature measurements
- Relative humidity measurements
- Date and time information
- Sensor observations
- Location information

## Data Organization

The collected observations are stored in separate datasets based on location and measurement type.

## Purpose

The collected data provides the foundation for studying microclimate variation and comparing climate conditions.
