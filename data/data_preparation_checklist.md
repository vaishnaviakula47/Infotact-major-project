# Data Preparation Checklist

Before climate data is passed to the analysis stage, basic preparation requirements should be checked.

## Checklist

The following items should be reviewed:

- Required dataset files are available.
- Temperature data is identified.
- Relative humidity data is identified.
- Date and time information is available.
- Sensor information is identified.
- Missing values have been reviewed.
- Duplicate records have been reviewed.
- Original raw data is preserved.

## Purpose

This checklist provides a simple reference for confirming that the datasets are ready for further analysis.

## Next Stage

Prepared data can be passed to the analysis layer for climate comparison and opportunity analysis.
