# Raw Data Preservation

The Autosync project should preserve the original climate datasets throughout the analysis process.

## Original Data

The raw temperature and relative humidity files should remain unchanged.

## Processing

Any cleaning, transformation, or derived information should be performed separately from the original datasets.

## Benefits

Preserving raw data allows:

- Original measurements to be reviewed.
- Processing steps to be repeated.
- Results to be compared with the original data.
- Errors to be traced back to the source.

## Purpose

Raw data preservation improves the reliability and traceability of the Autosync analysis.
