# Sensor Mapping

The Autosync temperature datasets contain readings from multiple sensors.

## Temperature Sensors

The dataset includes sensor columns such as:

- H16
- H17
- H18
- H19
- L17
- L18
- L20
- M16
- M18
- M19
- VH16
- VH17
- VH18
- VH19
- VL16
- VL17
- VL18
- VL19
- VL20

## Time Fields

- Date - Time: observation timestamp
- hour: observation hour

## Purpose

Sensor-level data allows the project to compare microclimate conditions across sensors and time periods.
