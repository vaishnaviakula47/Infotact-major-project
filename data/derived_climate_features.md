# Derived Climate Features

The Autosync project can derive additional climate features from the available temperature and relative humidity measurements.

## Possible Features

The analysis may derive:

- Temperature difference
- Humidity difference
- Temperature range
- Humidity range
- Time period
- Location identifier
- Sensor identifier

## Purpose

Derived features can provide additional information for comparing climate conditions between sensors and locations.

## Usage

These features can later be used by the analysis, visualization, and application layers.

## Data Preservation

Derived features should be created without modifying the original raw datasets.
