# Sensor Data Relationship

The Autosync project contains climate observations collected from multiple sensors.

## Sensor Observations

Each sensor can provide measurements associated with a particular location and time.

The observations may include:

- Temperature
- Relative humidity
- Date
- Time
- Sensor identifier

## Relationship

Sensor observations can be organized according to their location and recording time.

## Purpose

Understanding the relationship between sensors helps the analysis identify differences in climate conditions across sensor observations.

## Data Usage

Sensor-level information can be used by the analysis and visualization layers for microclimate comparisons.
