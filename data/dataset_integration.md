# Dataset Integration

The Autosync project uses multiple temperature and relative humidity datasets.

## Integration Requirements

Before combining datasets, the following information should be considered:

- Location
- Date and time
- Temperature measurements
- Relative humidity measurements
- Sensor information

## Integration Process

1. Identify the required datasets.
2. Check their date and time information.
3. Match datasets belonging to the same location.
4. Organize the measurements for further analysis.
5. Preserve the original raw datasets.

## Purpose

Dataset integration will allow temperature and humidity information to be analyzed together for microclimate analysis.
