# Sensor Statistics

The Autosync datasets contain measurements from multiple climate sensors.

## Temperature Sensor Statistics

Temperature sensor data can be analyzed using:

- Mean
- Minimum
- Maximum
- Standard deviation

## Purpose

These statistics help understand the typical temperature recorded by each sensor and the variation in measurements.

## Sensor Comparison

Comparing statistics between sensors can help identify differences in microclimate conditions.

## Future Use

The calculated statistics can support temperature comparison, visualization and microclimate analysis.
