# Climate Data Provenance

The Autosync project uses climate datasets containing temperature and relative humidity measurements.

## Data Source

The datasets are obtained from an external climate data source and are used for microclimate analysis.

## Data Types

The project contains:

- Temperature measurements
- Relative humidity measurements
- Date and time information
- Sensor observations
- Location information

## Data Usage

The datasets are used to study climate variation between locations, sensors, and time periods.

## Data Preservation

The original dataset should be preserved so that processed results can be traced back to the source data.
