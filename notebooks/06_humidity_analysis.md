# Humidity Analysis

Relative humidity (RH) data is used to understand humidity conditions across different sensors and locations.

## Analysis Areas

The humidity analysis can include:

- Mean humidity
- Minimum humidity
- Maximum humidity
- Humidity variation
- Sensor-level humidity differences
- Changes in humidity over time

## Purpose

Humidity analysis helps identify differences in microclimate conditions and provides additional information for the Autosync arbitrage analysis.

## Data Source

The analysis uses the relative humidity datasets available in the data folder.
