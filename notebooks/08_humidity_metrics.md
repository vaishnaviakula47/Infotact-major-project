# Humidity Metrics

Relative humidity data can be summarized using statistical metrics.

## Mean Humidity

The mean represents the average relative humidity recorded by the sensors.

## Minimum Humidity

The minimum value represents the lowest observed relative humidity.

## Maximum Humidity

The maximum value represents the highest observed relative humidity.

## Standard Deviation

Standard deviation can be used to understand how much humidity values vary around the average.

## Sensor Comparison

These metrics can be calculated for individual sensors to compare humidity conditions.

## Purpose

Humidity metrics provide a quantitative basis for understanding microclimate differences.
