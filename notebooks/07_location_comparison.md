# Location Comparison

The Autosync dataset contains climate observations from multiple locations.

## Locations

The available datasets include locations such as:

- Baltimore
- Denver
- Las Vegas
- Los Angeles

## Comparison

Temperature and humidity values can be compared between locations to identify differences in microclimate conditions.

## Analysis Purpose

Location comparison can help identify areas where climate conditions differ significantly.

These differences can later be examined as potential inputs for microclimate arbitrage analysis.
