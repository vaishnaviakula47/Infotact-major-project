# Opportunity Result Fields

The Autosync analysis should produce structured information for each identified climate opportunity.

## Result Fields

A result may contain:

- Location
- Date
- Time
- Temperature difference
- Relative humidity difference
- Sensor information
- Opportunity score
- Opportunity status

## Result Organization

The fields should be organized so that they can be passed to the visualization and application layers.

## Purpose

Structured result fields make analytical outputs easier to interpret, compare, and display.
