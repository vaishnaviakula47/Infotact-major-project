# Climate Distribution Analysis

Climate measurements can be examined to understand how values are distributed across observations.

## Measurements

The analysis may examine the distribution of:

- Temperature
- Relative humidity
- Sensor measurements
- Location measurements

## Analysis

Distribution analysis can help identify common values, variation, and unusual observations.

## Comparison

Distributions can be compared between sensors, locations, or time periods.

## Purpose

Understanding climate distributions provides additional information about microclimate conditions.
