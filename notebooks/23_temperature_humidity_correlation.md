# Temperature and Humidity Correlation Analysis

## Objective

This analysis examines the relationship between temperature and relative humidity in the climate datasets.

## Variables

The main variables are:

- Temperature
- Relative humidity
- Date and time
- Location
- Sensor identifier

## Analysis Approach

The analysis can compare temperature and humidity observations that belong to the same location, time period, and sensor where matching records are available.

The relationship can be examined using correlation analysis.

## Correlation

Correlation describes how two variables change in relation to each other.

A positive relationship means that the variables tend to increase together.

A negative relationship means that one variable tends to increase while the other decreases.

A value close to zero indicates a weak linear relationship.

## Steps

1. Load the temperature dataset.
2. Load the humidity dataset.
3. Identify matching location and time information.
4. Match relevant sensor observations.
5. Calculate correlation.
6. Compare the results across locations or sensors.
7. Document important observations.

## Project Relevance

Temperature and humidity relationships can help describe local micro-climate conditions.

These relationships may also provide useful input for identifying climate differences that can later be evaluated by the arbitrage analysis.

## Interpretation

Correlation should be interpreted as a statistical relationship.

It should not automatically be treated as proof that one climate variable causes changes in another.
