# Microclimate Comparison Method

Microclimate conditions can be compared using temperature and relative humidity observations.

## Comparison Factors

The analysis can compare:

- Temperature between sensors
- Humidity between sensors
- Temperature between locations
- Humidity between locations
- Changes over time

## Sensor-Level Comparison

Individual sensor measurements can be compared to identify differences in local environmental conditions.

## Location-Level Comparison

Measurements from different locations can be compared to identify broader climate differences.

## Purpose

The comparison provides analytical information that can later support identification of potential microclimate arbitrage opportunities.
