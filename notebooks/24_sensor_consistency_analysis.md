# Sensor Consistency Analysis

## Objective

Sensor consistency analysis checks whether sensors within the same climate dataset show similar or different patterns.

## Data Used

The analysis can use:

- Temperature sensor readings.
- Humidity sensor readings.
- Sensor identifiers.
- Date and time.
- Location.

## Analysis Steps

1. Identify all available sensors.
2. Calculate basic statistics for each sensor.
3. Compare sensor averages.
4. Compare minimum and maximum values.
5. Compare variation between sensors.
6. Identify sensors with substantially different patterns.
7. Document the findings.

## Sensor Comparison

For each sensor, useful metrics include:

- Mean
- Minimum
- Maximum
- Standard deviation
- Number of observations

These metrics allow differences between sensors to be examined systematically.

## Interpretation

A difference between sensors does not automatically mean that a sensor is incorrect.

Different sensors may capture different micro-climate conditions because of their physical locations.

## Project Relevance

Sensor-level differences are important for micro-climate analysis.

Understanding sensor variation can help identify localized climate conditions that may be relevant to later opportunity and arbitrage analysis.

## Output

The analysis should produce a clear comparison of sensor behavior and identify sensors that require further investigation.
